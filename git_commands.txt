Command to create new git repo on local and initialise it :
Step 1: Navigate to your project
cd /path/to/your/project
Step 2: Initialize a local Git repository
git init
Step 3: Add all files
git add .
Step 4: Commit the files
git commit -m "Initial commit"
Step 5: Create an empty repository on GitHub
https://github.com/<your-username>/<repository-name>
Step 6: Add the GitHub repository as the remote
git remote add origin https://github.com/siddharthsri2003/mypython_repo.git
Step 7: Rename the default branch to main (if needed)
git branch -M main
Step 8: Push the code to GitHub
git push -u origin main

1. Switch between different Git repositories:
cd /path/to/repo1
git remote -v
git status
pwd

See all local and remote branches:
git branch -a

Check which repository you're currently in:
git rev-parse --show-toplevel

1. to check branch
=> git branch
2.  to rename branch 
=> git branch -M main
3. to load difference branch 
=> git checkout <branch name>
4. To create new branch 
=> git checkout -b <new branch name>
5. To delete a branch 
=> git branch -d <branch name>
6. push new branch to GIT
=>git push origin feature1
7. get difference between two branches
=> get diff <other branch name>
8. TO merge two branches .
=> create PR merge
9. Merge conflicts
=> git merge main
